# PROJECT REPORT
## Student Performance Analytics Using Python

### 1. Introduction
Student performance analysis helps identify patterns in examination results and understand how different student-background and preparation variables are associated with academic performance. This project analyzes the Kaggle **Students Performance in Exams** dataset using Python.

### 2. Dataset Source
Dataset: Students Performance in Exams  
Source: Kaggle  
URL: https://www.kaggle.com/spscientist/students-performance-in-exams

The dataset contains 1,000 student records and 8 original variables: gender, race/ethnicity, parental level of education, lunch, test preparation course, math score, reading score, and writing score.

### 3. Problem Statement
Educational performance data can contain useful patterns that are difficult to identify by looking at individual records. The purpose of this project is to analyze student examination scores and compare performance across selected demographic and preparation-related groups.

### 4. Objectives
1. Load and inspect the dataset.
2. Check data quality, missing values, and duplicates.
3. Calculate total and average student scores.
4. Categorize students into performance levels.
5. Compare performance by gender.
6. Examine the relationship between test preparation and scores.
7. Compare average performance across parental education groups.
8. Study relationships between reading, writing, and math scores.
9. Produce clear visualizations and analytical outputs.

### 5. Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code / Jupyter-compatible Python environment

### 6. Methodology
#### Step 1: Data Loading
The CSV file is loaded using Pandas.

#### Step 2: Data Cleaning
Column names are standardized. Missing values and duplicate rows are checked. Duplicate rows, if present, are removed.

#### Step 3: Feature Engineering
Two calculated fields are created:
- Total Score = Math + Reading + Writing
- Average Score = Total Score / 3

A performance category is also created:
- Excellent: 80 or above
- Good: 60–79.99
- Average: 40–59.99
- Needs Improvement: below 40

These categories are project-defined analytical labels, not official grading standards.

#### Step 4: Exploratory Data Analysis
Group averages are calculated for gender, lunch type, test preparation, and parental education.

#### Step 5: Visualization
Charts are generated for score distribution, group comparisons, subject relationships, and correlation.

### 7. Key Analysis Areas
#### Gender
The project compares average scores for male and female students across the three subjects and overall average score.

#### Test Preparation
Students are grouped by whether they completed the test preparation course. Their average scores are compared to identify an association between preparation status and performance.

#### Parental Education
Average student performance is calculated for each parental education category.

#### Lunch Type
Average scores are compared between standard and free/reduced lunch groups. Lunch is treated only as a variable available in this dataset and should not be interpreted as a precise measure of family income.

#### Subject Correlation
A correlation heatmap is generated to examine how math, reading, and writing scores move together.

### 8. Expected Insights
The analysis can reveal:
- Which subject has the highest overall average.
- How average performance differs between test-preparation groups.
- How average performance varies across parental education categories.
- How strongly the three subject scores are correlated.
- The distribution of students across the project-defined performance levels.

The exact numerical results are generated by `main.py` from the downloaded CSV rather than hard-coded into this report.

### 9. Limitations
- The dataset is observational, so associations should not be interpreted as causal effects.
- The dataset represents a particular sample and should not automatically be generalized to every student population.
- Lunch type is not a complete socioeconomic measure.
- The dataset contains exam scores but does not contain many potentially relevant factors such as study hours, attendance, teaching quality, or school resources.

### 10. Conclusion
This project demonstrates a complete beginner-to-intermediate data analytics workflow: data loading, data quality checking, feature engineering, descriptive analysis, group comparison, visualization, and insight generation. It can be extended with SQL, Power BI, statistical testing, or machine-learning models.
